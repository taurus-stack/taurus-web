# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Taurus Web
- Modern Vue 3 + TypeScript + Vite setup
- Element Plus UI integration
- fast-crud framework for rapid CRUD development
- RBAC permission system with menu, button, and field level control
- WebSocket support for real-time updates
- Responsive design for desktop and mobile
- Dark/Light theme support
- Internationalization (i18n) ready
- Host management module
- Schedule management module
- Template management module
- Workflow management module

### Changed
- Renamed from Orion Web to Taurus Web
